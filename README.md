# Hugo ဘလော့ဂ် (SSG ပက်ကေ့ချ်ဖြင့် ဖန်တီးထားသည်)

GitHub Pages ပေါ်တွင် Public ဘလော့ဂ်တစ်ခု ထုတ်ဝေရန် **Hugo 0.167.0** ဖြင့် ဆောက်ထားသော အသင့်သုံး Repository ဖြစ်ပါသည်။ စာသားများကို မြန်မာဘာသာဖြင့် (လိုအပ်ပါက မြန်မာ–အင်္ဂလိပ် နှစ်ဘာသာဖြင့်) ရေးနိုင်ပြီး ASCII art၊ E-Ink ဖတ်ရှုမှု၊ စက္ကူပုံစံ နောက်ခံတို့ကို ဦးစားပေး ဒီဇိုင်းလုပ်ထားပါသည်။

> **အဓိကအချက်** — ကွန်ပျူတာတွင် ဘာမျှ install လုပ်ရန် မလိုပါ။ ဝက်ဘ်ဆိုက်ကို GitHub Actions က အလိုအလျောက် build လုပ်၍ ထုတ်ဝေပေးပါသည်။ ပို့စ်များကို ဖုန်း သို့မဟုတ် တက်ဘလက်မှ တင်နိုင်ပါသည်။

> **ယခုအခြေအနေ** — Hugo ကို ဤနေရာတွင် မ run ထားသဖြင့် (Local compiler မသုံးရန် သတ်မှတ်ထားသောကြောင့်) ပထမဆုံး **Actions run** သည် ပထမဆုံး အမှန်တကယ် စစ်ဆေးမှု ဖြစ်ပါသည်။ ပျက်ပါက အောက်ပါ "ပြဿနာဖြေရှင်းခြင်း" ကိုကြည့်၍ log ကို Claude Code သို့ ပေးပါ။

│   ├── my/                     မြန်မာဘာသာ (မူလ၊ ဝက်ဘ်ဆိုက် root တွင် ပေါ်သည်)

### ဦးစွာ ပြင်ရန် (TODO(owner))

`SITE-DECISIONS.md` တွင် အပြည့်အစုံပါသည်။ အဓိကအချက်များ —

1. `hugo.toml` — `title`၊ `description`၊ `tagline`၊ `author`၊ `githubRepo` (`"သင့်အမည်/repo-အမည်"`)

4. နမူနာပို့စ် ၃ ခုကို မလိုတော့လျှင် ဖျက်ပါ

## ၂။ စတင်ရန် (ဖုန်း သို့မဟုတ် တက်ဘလက်မှ)

1. GitHub တွင် Repository အသစ်တစ်ခု ဖွင့်ပါ။ **Public** ကို ရွေးပါ (အခမဲ့ GitHub Pages အတွက် Public ဖြစ်ရပါမည်)။
   - ဝက်ဘ်ဆိုက်လိပ်စာမှာ `https://<သင့်အမည်>.github.io/<repo-အမည်>/` ဖြစ်ပါမည်။
   - Repository အမည်ကို `<သင့်အမည်>.github.io` ဟု ပေးပါက လိပ်စာမှာ `https://<သင့်အမည်>.github.io/` ဖြစ်ပါမည်။
2. ဤ Repository ၏ ဖိုင်များကို အလုံးစုံ တင်ပါ။
   - **Add file → Upload files** ဖြင့် `README.md`၊ `CLAUDE.md`၊ `SPECIFICATIONS.md` ကဲ့သို့ ဖိုလ်ဒါမပါသော ဖိုင်များကို တင်နိုင်ပါသည်။
   - `.claude` နှင့် `.github` ကဲ့သို့ အစက်ဖြင့်စသော ဖိုလ်ဒါများသည် ဖုန်း၏ ဖိုင်ရွေးစနစ်တွင် မမြင်ရနိုင်ပါ။ ထိုအခါ **Add file → Create new file** ကိုနှိပ်ပြီး ဖိုင်အမည်ကွက်တွင် `.claude/skills/ssg-site-builder/SKILL.md` ဟု ရိုက်ပါ။ `/` ကို ရိုက်လိုက်သည်နှင့် ဖိုလ်ဒါ အလိုအလျောက် ဖြစ်လာပါမည်။ ထို့နောက် ဖိုင်၏ စာသားကို ကူးထည့်ပြီး **Commit** လုပ်ပါ။
   - ဖိုင်များ အလွန်များသဖြင့် (ဖောင့်များ၊ template များ အပါအဝင်) ဖုန်းမှ တစ်ခုချင်းတင်ရန် ခက်ပါသည်။ **GitHub ၏ ဝက်ဘ်ဆိုက်ကို ကွန်ပျူတာ browser ဖြင့်ဖွင့်၍ ဖိုလ်ဒါအလိုက် drag-and-drop လုပ်ခြင်း** (သို့မဟုတ် `git push`) ကို အကြံပြုပါသည်။ ဖုန်းမှ တင်ပါက အနည်းဆုံး `.github/workflows/deploy.yml` ကို Create new file ဖြင့် ဖန်တီးရပါမည်။
3. **Settings → Pages → Build and deployment → Source** တွင် **GitHub Actions** ကို ရွေးပါ။
4. (ရွေးချယ်စရာ) Claude Code (web သို့မဟုတ် ဖုန်းအက်ပ်) တွင် ဤ Repository ကို ဖွင့်ပြီး ပြင်ဆင်လိုသည်များကို ပြောပါ။ SSG (Hugo) ကို ရွေးပြီးဖြစ်သဖြင့် AI က ထပ်မမေးတော့ပါ။ `SITE-DECISIONS.md` တွင် မှတ်ထားပြီး ဖြစ်ပါသည်။
5. AI ၏ အလုပ်ပြီးသည်နှင့် **Actions** tab တွင် အစိမ်းရောင် ✓ ပေါ်လာပါက ဝက်ဘ်ဆိုက် တင်ပြီးဖြစ်ပါသည်။ အနီရောင် ✗ ဖြစ်ပါက အောက်ပါ "ပြဿနာဖြေရှင်းခြင်း" ကို ကြည့်ပါ။

> **SSG ပြောင်းလိုလျှင်** — `SPECIFICATIONS.md` ၏ အပိုဒ် ၃ နှင့် `templates/workflows/` ကိုကြည့်ပါ။ ပြောင်းရန် Claude Code ကို ခိုင်းနိုင်ပါသည် (ပို့စ်များသည် Markdown ဖြစ်၍ ဆက်သုံးနိုင်ပါသည်)။

## ၃။ စာသား (Content) ရေးသားနည်း

အကြောင်းအရာများကို Markdown (`.md`) ဖိုင်များအဖြစ် ရေးသားပြီး GitHub သို့ Commit လုပ်လိုက်သည်နှင့် ဝက်ဘ်ဆိုက် အလိုအလျောက် ပြန်လည်တည်ဆောက်ပါသည် (များသောအားဖြင့် ၁–၃ မိနစ်အတွင်း)။

အသေးစိတ်ကို **`docs/CONTENT-GUIDE.md`** တွင် ဖတ်ပါ — front matter၊ ညီမျှခြင်း၊ ဇယား၊ ပုံ၊ ASCII art၊ နှစ်ဘာသာပြသနည်း စသည်တို့ ပါဝင်ပါသည်။

စာမျက်နှာအသစ်ထည့်လိုလျှင် Claude Code ကို ဤသို့လည်း ခိုင်းနိုင်ပါသည် —
"docs အောက်တွင် 'PID ညှိနည်း' စာမျက်နှာအသစ်ထည့်ပါ၊ ကျွန်ုပ်၏ မှတ်စုမှာ ... ဖြစ်ပါသည်။"

## ၄။ ဒီဇိုင်း အကျဉ်းချုပ်

| ပုံစံ | အကြောင်း |
|-------|----------|
| **Paper** (မူလ) | နူးညံ့သော အဖြူရောင်နှင့် မီးခိုးဖျော့ရောင်၊ စက္ကူသားကဲ့သို့ အလွန်ပါးသော grain၊ သန့်ရှင်းသော minimalist ပုံစံ |
| **E-Ink** | အဖြူ/အနက်သက်သက်၊ ရွေ့လျားမှု/အရိပ်/ဝါးမှု မရှိ၊ စာလုံးကြီး၊ စာမျက်နှာလှန်ကဲ့သို့ ရှေ့/နောက် ခလုတ်များ |
| **Dark** | စနစ်က dark ဖြစ်လျှင် အလိုအလျောက် သုံးသည် |
| **Glass** (ရွေးချယ်စရာ) | Liquid Glass / Dynamic Island / Hyprland ပုံစံ ပွင့်လင်းမြင်ရမှု — မူလအားဖြင့် ပိတ်ထားပြီး E-Ink တွင် လုံးဝမသုံးပါ |

- **ASCII art** သည် ဝက်ဘ်ဆိုက်၏ အဓိက အမှတ်လက္ခဏာ ဖြစ်ပါသည် (ခေါင်းစဉ်၊ ပိုင်းခြားမျဉ်း၊ 404 စာမျက်နှာ စသည်)။
- ဝက်ဘ်ဆိုက်၏ ထိပ်ပိုင်းတွင် ပုံစံပြောင်းခလုတ်များ (Paper / E-Ink / Dark)၊ စာလုံးအရွယ် `A−` `A+` နှင့် ဘာသာပြသမှု (မြန်မာ / English / နှစ်ဘာသာ) ခလုတ်များ ပါဝင်ပါမည်။ ရွေးချယ်မှုကို ဖုန်း၏ browser တွင် မှတ်ထားပါမည်။
- E-Ink ဖန်သားပြင်ဖြစ်ကြောင်း browser က ဖော်ပြပါက E-Ink ပုံစံကို အလိုအလျောက် သုံးပါမည်။ မဖော်ပြသော browser များတွင် ခလုတ်ဖြင့် ကိုယ်တိုင်ရွေးပါ။

## ၅။ ပြဿနာဖြေရှင်းခြင်း

- **Actions တွင် အနီရောင် ✗ ပေါ်နေသည်။** Actions tab → ပျက်သွားသော run ကိုနှိပ်ပါ → အနီရောင်ဖြစ်သော အဆင့်ကို ဖွင့်ပါ။ အမှားစာသားကို ကူးယူပြီး Claude Code သို့ ပို့ပါ။ AI က ပြင်ပေးပါမည်။
- **Actions တွင် Hugo အမှား (ဥပမာ template ... error) ပေါ်နေသည်။** ပထမဆုံး run ဖြစ်ပါက template တစ်ခုခု ပြင်ရန် လိုနိုင်ပါသည်။ ပျက်သော run ၏ log ကို Claude Code သို့ ကူးပေးပါ။
- **ဝက်ဘ်ဆိုက်လိပ်စာတွင် 404 ပေါ်နေသည်။** Settings → Pages တွင် Source သည် **GitHub Actions** ဖြစ်မဖြစ်၊ Repository သည် **Public** ဖြစ်မဖြစ် စစ်ပါ။ ပထမဆုံး Actions run ပြီးသည်အထိ ခဏစောင့်ပါ။
- **စာမျက်နှာ ပေါ်သော်လည်း ပုံစံ (CSS) မပါ၊ ပုံများ မပေါ်ပါ။** Base path မှားနေခြင်း ဖြစ်နိုင်သည်။ Repository အမည်ကို `SITE-DECISIONS.md` တွင် မှန်ကန်စွာ ဖြည့်ထားမထားစစ်ပြီး AI ကို "base path ကို စစ်ပါ" ဟု ခိုင်းပါ။
- **မြန်မာစာ ပျက်နေသည် (အက္ခရာများ ရောထွေးနေသည်)။** Zawgyi ဖြင့် ရိုက်ထားခြင်း ဖြစ်နိုင်ပါသည်။ ဤဝက်ဘ်ဆိုက်သည် **Unicode** ကိုသာ လက်ခံပါသည်။ Unicode ကီးဘုတ် (ဥပမာ Pyidaungsu / Myanmar3) ဖြင့် ပြန်ရိုက်ပါ။ Actions တွင် "Zawgyi ဖြစ်နိုင်သည်" ဟု သတိပေးချက် ပေါ်လာပါမည်။
- **ညီမျှခြင်း မပေါ်ပါ။** `$ ... $` (စာကြောင်းအတွင်း) သို့မဟုတ် `$$ ... $$` (သီးသန့်စာကြောင်း) ကို သုံးပါ။
- **Content ပြောင်းလိုက်သော်လည်း ဝက်ဘ်ဆိုက်တွင် မပြောင်းပါ။** Actions run အောင်မြင်ကြောင်း စစ်ပါ။ ပြီးလျှင် browser ၏ cache ကို ဖျက်ပါ သို့မဟုတ် စာမျက်နှာကို ပြန်လည်ဖွင့်ပါ။

## ၆။ မှတ်ချက်များ

- **Fonts** — ဖွင့်လှစ်ထားသော လိုင်စင် (SIL OFL စသည်) ရှိသော ဖောင့်များကိုသာ သုံးပါသည်။ ဖောင့်ဖိုင်များကို ဝက်ဘ်ဆိုက်ကိုယ်တိုင်မှ host လုပ်ပါသည် (ပြင်ပ server များသို့ တောင်းဆိုမှု မရှိပါ)။
- **အမှတ်တံဆိပ်များ** — Apple၊ Claude၊ OpenAI၊ Nothing တို့၏ ဖောင့်၊ လိုဂို၊ ကုဒ်များကို မကူးယူပါ။ ၎င်းတို့၏ **ခံစားမှု** ကိုသာ မူရင်း CSS ဖြင့် ဖန်တီးပါသည်။
- **လိုင်စင်** — သင့်စာသားများအတွက် လိုင်စင် (ဥပမာ CC BY) ကို သင်ဆုံးဖြတ်ပြီး `LICENSE` ဖိုင် ထည့်နိုင်ပါသည်။ ယခုအခါ မသတ်မှတ်ရသေးပါ။
- **ကိုယ်ရေးအချက်အလက်** — ဝက်ဘ်ဆိုက်တွင် ကိုယ်ရေးရာဇဝင်၊ အလုပ်အကိုင်၊ ဆက်သွယ်ရန် အချက်အလက်များကို AI က မဖန်တီးပါ။ `TODO(owner)` အမှတ်အသားဖြင့် သင့်ကိုယ်တိုင် ဖြည့်ရန် ချန်ထားပါမည်။
